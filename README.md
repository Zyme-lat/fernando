# Fragancias Aluhe - Embudo para revendedoras

Landing page estática para presentar la propuesta comercial de Perfumes Aluhe a revendedoras. Incluye:

- Sección hero con posicionamiento de marca y llamada a la acción.
- Packs por cantidad con precios unitarios para 500 cc y 250 cc.
- Tabla de ganancias estimadas según precio sugerido al público.
- Calculadora interactiva para simular inversión y ganancia total.
- Pasos de conversión y CTA final hacia Instagram.

## Cómo verlo localmente

Abrí `index.html` en el navegador o levantá un servidor estático:

```bash
python3 -m http.server 8000
```

Luego visitá `http://localhost:8000`.
